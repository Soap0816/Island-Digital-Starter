# Island Digital Starter

Reusable Next.js 16 + Tailwind 4 + Motion foundation for Island Digital client websites.

```bash
npm install
npm run dev      # http://localhost:3000 — demo homepage showing every component
npm run lint
npm run build
```

Rebrand a project from **`src/data/site.ts`**. See **[AGENTS.md](./AGENTS.md)** for the architecture, theming rules and the new-client checklist.
